### Added
- Initial release
- `TranslatableInput` field: multi-language text/textarea whose value is an array keyed by locale, with a globe popover to edit every locale, per-locale validation rules (`name.en`, `name.ar`, ...) and a new `laravilt-forms.locales` config key that accepts plain codes or per-locale `name`/`direction`/`label` metadata. Shipped for Blade, Vue and React.
